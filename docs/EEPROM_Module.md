# EEPROM Module
[←Top](../README.md)<BR>
A EEPROM module is used to store rain day totals, position location in the Need to Send file of what has been sent. This information needs to be non-volitile across station reboots.

Use the below EEPROM module
- [Adafruit 24LC32 I2C EEPROM Breakout - 32Kbit / 4 KB - Stemma QT](https://www.adafruit.com/product/5146)

## Wiring
The module connects to the i2c bus.
